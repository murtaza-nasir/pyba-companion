Anscombe's quartet: four datasets constructed to share the same correlation (r = 0.82), the same means, and the same fitted line. Dataset I is a genuine linear relationship; II is a smooth curve; III is a line with one outlier; IV is a vertical stack with one point. The summary statistics are identical across the four; the differences are visible only in a plot. For this reason, we always pair the number with the plot.
