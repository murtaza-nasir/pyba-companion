The actual values are fixed; the predicted values are editable. The two presets "eight small errors" and "one large error" have the same average absolute error, $100, yet their RMSEs differ by almost a factor of three, because each error is squared before averaging. Enter a large value in any predicted cell; you will see the RMSE respond far more than the average absolute error.
